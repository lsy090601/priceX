# PriceX 화면 구현 가이드

시안: [pricex-screen-concepts.svg](./pricex-screen-concepts.svg)

## 화면 흐름

1. **홈**: 상품 검색, 최근 가격 동향, 장보기 예상 총액, 빠른 메뉴
2. **검색 결과**: 상품명·제조사·조사일, 최저·평균 가격, 매장 수
3. **상품 상세**: 최저·평균·최고 가격, 다음 달 예측, 판매점별 가격, 장보기 추가
4. **장보기 목록**: 수량 변경, 구매 완료, 예상 총액, 추천 화면 이동
5. **구매처 추천**: 상품별 최저 구매처, 총액, 예상 절약액, AI 설명

## 공통 표시 규칙

- 가격에는 항상 조사일을 함께 표시한다.
- 예측값에는 `예상`이라는 표현과 신뢰도를 표시한다.
- 상승·하락 판정 색상만으로 의미를 전달하지 않고 문구를 함께 쓴다.
- AI가 가격이나 절약액을 계산하지 않는다. 서버 계산 결과를 설명하는 용도로만 사용한다.
- AI 호출이 실패하면 계산 기반 조언을 그대로 표시한다.
- 세일과 1+1 가격은 일반 가격과 구분한다.

## 개발 연결

| 화면 | 사용할 기능 |
|---|---|
| 검색 결과 | `search_price_products` RPC |
| 상품 상세 | `compare_product_prices`, `search_price_forecasts` RPC |
| 장보기 목록 | 팀원 체크리스트 테이블 및 수량 상태 |
| 구매처 추천 | `recommend_purchase_plan` RPC |
| AI 구매 조언 | `createAiShoppingAdvice` 서비스 |

## 우선 구현 순서

1. 검색 결과
2. 상품 상세
3. 장보기 목록 연동
4. 구매처 추천
5. AI 구매 조언
